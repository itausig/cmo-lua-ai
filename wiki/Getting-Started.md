# Getting Started

## 1) Choose your workflow

- **AI-assisted scripting:** use `.cursorrules` or `CONTEXT.md`
- **Manual scripting:** use docs + copy modules from `src/lib/`

## 2) Learn the core API groups

- `ScenEdit_*` for scenario mutation
- `VP_*` for view/read operations
- `Tool_*` for utility calculations
- `World_*` for world queries
- `UI_*` for player-facing UI actions

## 3) Understand execution contexts

- **Lua Console:** interactive debugging, visible errors
- **Event scripts (TCA):** silent failures; use defensive error handling

## 4) Use examples and templates

- Templates: `src/templates/`
- End-to-end examples: `src/examples/`
- Practical patterns: `docs/patterns/`
