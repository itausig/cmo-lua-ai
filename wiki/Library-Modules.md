# Library Modules

`src/lib/` is organized by scenario concern:

- `combat/` — attack and damage helpers
- `movement/` — route and formation logic
- `sensors/` — detection and LOS helpers
- `logistics/` — fuel and resupply flows
- `events/` — trigger/action building helpers
- `missions/` — mission creation/management
- `doctrine/` — doctrine and WRA helpers
- `zones/` — reference point/area handling
- `emcon/` — emissions control
- `scoring/` — side scoring/state
- `ui/` — message and UI utilities
- `cargo/` — transport/cargo flows
- `weather/` — weather operations

See `src/examples/` for integration-style usage.
